# Решения по реализации API v1

Реализован базовый управляющий контур с интеграцией Worker через PostgreSQL/RabbitMQ. Общие контракты сообщений определены согласованными обсуждениями deployment-request и job-progress. Локальное выполнение использует детерминированные адаптеры симуляции. Облачное выполнение, мониторинг Doctor и Notifications ожидают реализации.

| Решение | Базовый вариант |
| --- | --- |
| Идентификация | Bearer-токены Keycloak/OIDC. Уникальная пара `(issuer, subject)` сопоставляется с UUID пользователя, созданным сервером. |
| Локальная аутентификация | Импортируемый realm Keycloak, браузерный PKCE-клиент, пользователь для разработки и отдельный клиент сервисной учётной записи для проверки через CLI. |
| Владение схемой | Один проект `CloudSwitch.Persistence` и история миграций. Отдельный однократный процесс применения миграций. |
| Хранение | PostgreSQL/EF Core. Структурированные определения и снимки в JSONB, владение, ограничения и прогресс в индексируемых реляционных столбцах. |
| Конфигурация | Зарегистрированный источник, закреплённый образ, ресурсы, настройки, ссылки на секреты, политика здоровья и восстановления, настройки трафика. Целевые окружения используют определения модулей и ревизий, одобренные оператором. |
| Ревизии | Возрастающие ревизии развёртывания и цели. ETag/If-Match при замене и мягком удалении. Конфигурация заморожена при активном задании. |
| Секреты | Ссылки `vault://path#key`, включая необязательные данные доступа к реестру. Значения разрешаются при выполнении. Запросы заданий исключают учётные данные, произвольные источники модулей и пользовательский HCL. |
| Создание задания | Общий сервис API/Doctor. Неизменяемый снимок источника, цели, приложения, здоровья и трафика сохраняется вместе с исходящим запросом через EF/MassTransit bus outbox. |
| Конкурентность | Транзакционная advisory-блокировка PostgreSQL на развёртывание и уникальные индексы для активной миграции, ручного ключа и автоматического задания инцидента. |
| Идемпотентность | Ручной ключ действует в пределах развёртывания. Та же цель возвращает исходное задание, другая — 409. Повтор автоматического инцидента возвращает исходное задание, включая завершившееся неудачей. |
| Автоматическое восстановление | Транзакция повторно проверяет мониторинг, Automatic и одобренную цель, текущий нездоровый инцидент и последовательность, ревизии конфигурации и активного окружения. Unknown не создаёт задание. |
| Активное окружение и здоровье | Запись принадлежит Worker. До инициализации источником служит регистрация. При отсутствии актуального наблюдения возвращается Unknown. |
| Прогресс | Pending → Running → Succeeded/Failed. Фазы Pending, Provisioning, TargetValidation, TrafficCutover, EntrypointVerification, Completed. Результаты переключения NotStarted, Applied, Verified, Uncertain. |
| Надёжность Worker | Аренды PostgreSQL с проверкой владельца, fencing и срока, продление heartbeat, ограничение попыток восстановления и сохранённая последовательность. Прогресс, история и исходящие события фиксируются через EF/MassTransit bus outbox. |
| Границы выполнения | Worker проверяет здоровье и точку входа перед успехом, ограничивает попытки, продлевает аренды и блокирует устаревших владельцев, сверяет контрольные точки и сохраняет инфраструктуру источника при сбое. API не записывает состояние выполнения. |
| Получение конфигурации Doctor | Начальный Worker читает активную конфигурацию PostgreSQL при запуске и опрашивает ревизии. События и координация реплик отложены. |
| Брокер | Постоянные exchanges, очереди и bindings создаются до публикации. API не читает очереди Worker/Notifications. |
| Совместимость | Существующие URN сообщений и фикстуры v1 сохранены. Снимок миграции, причина запуска, инцидент и детали прогресса добавлены совместимым расширением. API преобразует замороженный снимок PostgreSQL в согласованный плоский `DeploymentSpecification` с `DeploymentTrigger`, целью и модулем, ресурсами, ссылками Vault, политикой здоровья и точкой входа. |

См. [API и примеры](../api.md), [доменную модель](../domain-model.md), [контракты](../contracts.md) и [права ролей](../../../src/CloudSwitch.Persistence/DatabasePermissions.sql).
